Substituir template

Seleciona o template e envia um novo arquivo. A substituição exige confirmação, preserva a versão anterior como backup (modo API) e avisa que as coordenadas podem precisar de revisão.

Editor de Coordenadas

Selecione o template, visualize a página e arraste os campos. O sistema de coordenadas é o mesmo do pdf-lib: origem no canto inferior esquerdo, Y cresce para cima, unidade em pontos (pt).

Atalhos setas = mover (1 pt) · Shift+setas = 5 pts · Alt+setas = ajuste fino (0,5 pt) · Ctrl/Cmd+clique = seleção múltipla · L = alinhar · Shift+L = distribuir · R = restaurar

Segurança

        

          Proteção client-side. A verificação de e-mail deste painel segue o
          mesmo princípio do guard.js das rotas públicas: barreira no navegador, não
          autenticação server-side. Não deve ser tratada como controle de acesso forte.
          Evolução recomendada para operações destrutivas: autenticação server-side.
